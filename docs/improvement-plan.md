# 产品改进计划（2026-10-31）

依据：检查当前 README、主界面、MainViewModel 和现有功能测试。目标是降低手动挑选成本，并让清理结果及时反映在首页。

## 本轮执行范围

| 优先级 | 问题 | 改进与验收标准 |
| --- | --- | --- |
| P1 | 大量候选只能逐项查找勾选 | 按路径关键词搜索，忽略大小写和首尾空格；支持明确点击“勾选筛选结果”；默认仍不勾选，筛选本身不改变选择；清理预览包含所有已选项 |
| P1 | 筛选后容易遗漏已勾选文件 | 显示筛选数量、全部已选大小和隐藏的已选数量；取消勾选清除全部选择；新扫描清空搜索条件；无匹配时给出恢复操作提示 |
| P1 | 清理后首页仍显示旧磁盘容量 | 手动与一键清理均使用执行报告的操作后磁盘快照更新首页；保留实际空间变化与逻辑大小的区别 |
| P1 | 批量操作可能让界面卡顿或执行范围失真 | 批量勾选集中更新汇总和失效预览；操作期间禁用勾选；测试筛选、隐藏选择、重新扫描、确认后执行范围和真实 WPF 布局 |

## 后续迭代（本轮不承诺交付）

1. P0 发布验收：在干净 Windows 11 虚拟机验证 ZIP 首次启动、普通账户权限、不同 DPI、回收站与被占用文件；形成可复现的验收记录后再正式发布。
2. P2 结果排障：提供成功/失败/跳过筛选与脱敏报告导出，明确导出包含哪些本地路径信息。
3. P2 设置反馈：对无效阈值就地提示，区分已保存与未保存状态，减少执行后才发现输入错误。
4. P2 扫描体验：区分临时文件和大文件页面的扫描会话，并在大规模目录上验证首屏响应、搜索延迟和内存峰值。

## 验证方式

运行 Release 构建和全量自动化测试；新增测试覆盖筛选不删除文件、批量选择只作用于可见结果、隐藏选择被明确提示、选择变更使预览失效、重新扫描重置筛选、报告刷新首页。WPF 渲染使用隔离测试数据，不操作用户临时文件。测试结果完成后记录于本文件。
