# 使用说明

1. 解压自包含 ZIP，在 Windows 11 x64 上启动 `Clean.exe`。无需另装 .NET，不要求管理员权限。未签名包可能显示来源提示，请核对来源和 SHA-256，不关闭系统保护。
2. 在“概览”查看磁盘和物理内存。在“设置与历史”添加不希望扫描/处理的排除目录并保存。
3. “临时文件”只扫描当前用户 Temp，默认排除 7 天内修改的文件。“大文件分析”需主动指定本地目录，默认阈值 100 MiB。
4. 查看路径、修改时间和规则依据后逐项勾选。所有文件初始不选；大文件并不等于垃圾。结果默认按逻辑大小降序，路径可横向滚动查看，扫描表格的路径悬停显示完整文本。
5. 生成清理预览，默认移入回收站。永久删除需切换方式、重新生成预览并在单独对话框确认。修改扫描范围或阈值后须重新扫描。
6. 执行中可以切换页面并停止后续调度。正在执行的 Windows 操作返回后才结束；已完成操作不能回滚。窗口关闭时先取消任务并等待系统操作返回。
7. 在结果页查看成功/跳过/失败/未执行，以及回收站与永久删除数量。逻辑大小不是释放空间；可用空间变化也可能来自其他程序。
8. 回收站文件请在 Windows 回收站中右键“还原”。清空回收站入口影响当前用户所有磁盘，具有应用和系统两次独立确认，不能恢复保证。

内存页可见且未最小化时约 2 秒采样。工作集不能相加当作物理内存使用量；程序不结束进程或强制释放工作集。

配置在 `%LOCALAPPDATA%\Clean\settings.json`，上次有效版本为 `.bak`；损坏会回退到备份或默认值，并显示提示。历史最多 50 条，只含摘要。日志只保留事件类别，不记录文件路径；可在设置页清除历史和日志。中断任务不会在重启后继续删除。

一次扫描最多保留 100000 个候选、1000 条错误样本，深度上限 128。达到候选上限会显示结果不完整，建议缩小范围。拒绝 UNC、设备路径、重解析点以及 Windows/程序安装/系统数据保护目录。只读、系统或多硬链接文件执行时跳过；不改变权限、不关闭占用程序。

已知限制与验证状态见 test-report.md。回收站使用路径接口，无法消除同用户恶意进程最后瞬间替换叶文件的全部竞态。尚未验证的清空回收站与多 DPI 场景应先在隔离环境验收。
