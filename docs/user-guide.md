# 使用说明

1. 解压自包含 ZIP，在 Windows 11 x64 上启动 `Clean.exe`。无需另装 .NET，不要求管理员权限。未签名包可能显示来源提示，请核对来源和 SHA-256，不关闭系统保护。
2. 日常清理只需在首页点击“一键清理”：自动扫描当前用户 Temp 并**永久删除至少 7 天未修改的临时文件**，不进入回收站，不再弹窗确认。开始后自动出现“本次清理”卡片，可点“清理详情 →”查看进度和逐项结果。如果设置的年龄大于 7 天，使用设置值。
3. 在“设置与历史”添加不希望扫描/处理的排除目录并保存。一键清理遵守排除规则，不处理大文件分析结果或清空回收站；扫描阶段取消时不删除任何文件。
4. 需要自己挑选时使用“临时文件”或“大文件分析”。大文件分析需主动指定本地目录，默认阈值 100 MB。结果默认不勾选、按大小降序。
5. 手动模式可用“搜索路径”按关键词查找文件，再点击“勾选筛选结果”批量选择当前显示的文件。搜索忽略大小写和首尾空格，不会自动改变勾选状态；隐藏的已选文件仍在清理范围内，汇总会提示其数量。“取消全部勾选”包括隐藏选择；重新扫描会清空搜索和选择。生成预览后核对全部已选文件，默认移入回收站。手动永久删除仍需切换方式、重新生成预览并单独确认。修改扫描范围或阈值后须重新扫描。
6. 执行中可以切换页面并停止后续调度。正在执行的 Windows 操作返回后才结束；已完成操作不能回滚。窗口关闭时先取消任务并等待系统操作返回。
7. 左侧不再放置“清理详情”。它由本次清理卡片或手动预览打开，可查看成功/跳过/失败/未执行及删除方式，点“← 返回”回到来源页。手动任务结束后，可从扫描页的“本次结果”重新打开。手动和一键清理结束后，首页磁盘容量自动更新为执行报告中的操作后快照。逻辑大小不是释放空间；可用空间变化也可能来自其他程序。表格随内容显示，不预留大块白色区域。
8. 回收站文件请在 Windows 回收站中右键“还原”。清空回收站入口影响当前用户所有磁盘，具有应用和系统两次独立确认，不能恢复保证。

内存页可见且未最小化时约 2 秒采样。工作集不能相加当作物理内存使用量；程序不结束进程或强制释放工作集。

配置在 `%LOCALAPPDATA%\Clean\settings.json`，上次有效版本为 `.bak`；损坏会回退到备份或默认值，并显示提示。历史最多 50 条，只含摘要。日志只保留事件类别，不记录文件路径；可在设置页清除历史和日志。中断任务不会在重启后继续删除。

一次扫描最多保留 100000 个候选、1000 条错误样本，深度上限 128。达到候选上限会显示结果不完整，建议缩小范围。拒绝 UNC、设备路径、重解析点以及 Windows/程序安装/系统数据保护目录。只读、系统或多硬链接文件执行时跳过；不改变权限、不关闭占用程序。

已知限制与验证状态见 test-report.md。回收站使用路径接口，无法消除同用户恶意进程最后瞬间替换叶文件的全部竞态。尚未验证的清空回收站与多 DPI 场景应先在隔离环境验收。


容量单位按十进制显示：1 KB = 1000 B，1 MB = 1000 KB，1 GB = 1000 MB。旧版大文件设置自动换算，例如原 100 MiB 显示为 104.8576 MB，实际筛选字节数保持一致。
