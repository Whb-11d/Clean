# Clean v0.1 产品规格

状态：可实施。基线为 plan.md，2026-10-28。名称 Clean、MIT、中文 Windows 11 x64、自包含 ZIP 沿用计划假设。实际发布和远程仓库操作不在本次本地开发范围。

## 用户追加要求：一键清理与紧凑布局

2026-10-28 用户要求点击清理直接执行，取消日常流程的逐项勾选/预览。FR-15 新增首页“一键清理”：按钮旁事先明确显示永久删除、当前用户临时目录和最小年龄；点击即确认本次新扫描的限定规则文件，无二次弹窗。最小年龄为设置值与 7 天的较大值，排除目录继续生效；不包括大文件结果、回收站或用户另选目录。扫描被取消时不进入删除；占用、变化、受保护文件仍按项跳过/失败。执行仍使用不可变计划、逐项复核和历史。手动清理保留原确认流程，FR-05/07 的预览与单独弹窗要求适用于手动模式。

NFR-09：设置与结果页改为内容高度布局，空列表显示简短空状态而非空白表格；有内容的明细表设置最大高度并保持虚拟化。首页直接呈现清理按钮和结果摘要，不强制跳转。启动不自动清理。

所有文件初始均不勾选。不能把候选文件等同于垃圾。排除下载、桌面等默认清理行为；只有用户主动选择的大文件分析才会展示其内容。拒绝系统维护目录、UNC、设备路径、重解析点、目录删除及多硬链接文件执行。无注册表清理、进程终止、内存释放、更新和云功能。

NFR-01/03：后台扫描/清理，进度最多约每 100ms 更新，取消目标 2 秒停止调度（阻塞 OS 调用除外）。NFR-02：深度限制 128、候选上限 100000、错误样本上限 1000、历史最多 50 条；达到限制明确报告，不能暗示完整扫描。NFR-04：逐项故障隔离。NFR-05：逻辑大小与磁盘空间变化分开。NFR-06：运行时离线。NFR-07：虚拟化表格、可调整窗口、键盘焦点；三档 DPI 另测。NFR-08：执行前持久化“进行中”历史，完成覆盖；重启显示“中断”，绝不继续删除。

验证状态以 docs/test-report.md 为准；隔离 VM、干净机器和各 DPI 未验证时不宣称达到正式发布门槛。
