# 清理规格（FR-05～10、13）

计划是候选与规则、排除目录、方式的不可变快照，按路径去重，包含计划 ID 和创建时间。计划不能执行两次；选择/偏好/方式变化废弃预览。执行 API 必须接收与计划 ID、方式匹配的确认。手动模式对话框默认取消，永久删除采用独立提示；按用户追加要求，一键模式以明确标注“永久删除过期临时文件”的按钮点击作为确认，无额外勾选或弹窗。

一键模式仅新扫描当前用户临时目录，使用至少 7 天的年龄阈值及当前排除目录，不使用旧扫描结果或大文件选择。扫描取消则不清理；零候选不创建空计划；扫描错误/上限与执行的部分结果均明确报告。运行期间禁用重复启动和配置修改，可停止后续工作。无后台、启动时或计时自动清理。

逐项状态：Pending → Succeeded / Skipped / Failed / NotExecuted。取消后剩余项为 NotExecuted；当前 OS 操作返回真实结果。规则不匹配、路径越界、排除、文件变化或重解析点为 Skipped；OS 操作错误为 Failed。计划项目数等于所有结果数。结果保留路径、方式、原因、逻辑字节数。

执行前再次校验规则条件、路径边界和排除。Windows 实现通过文件句柄核对卷/文件 ID、长度、创建/修改时间、属性、单链接；从卷根到父目录保持不共享删除的目录句柄并验证最终路径。永久删除使用已验证的独占文件句柄 FileDispositionInfo，拒绝只读/系统/重解析/多链接文件。

回收站采用 IFileOperation，每次只提交一个文件，PreDeleteItem 再次验证身份并要求 TSF_DELETE_RECYCLE_IF_POSSIBLE；不允许系统回退到直接删除。成功必须取得 PostDeleteItem 成功回调及回收站新项。目录句柄贯穿操作。Shell 只接受路径，无法完全消除同用户恶意进程在最后校验后的叶文件替换竞态；这是明确的技术限制，见 ADR-002。不得宣称抵御同权限恶意进程；永久删除使用句柄避免该窗口。

清空回收站为全局独立操作，用 Windows Shell 确认和独立应用确认；前后查询数量/大小，失败或取消时报告可能部分执行，不把变化当作精确归因。自动化绝不清空真实回收站。

执行前写入历史进行中标记；每项完成落盘累计摘要，写入失败停止调度。重启保留中断记录，不自动执行。历史仅保留摘要，不保留完整文件路径；当前会话提供逐项详情。回收站文件通过 Windows 回收站手动还原。逻辑大小不代表释放空间，磁盘可用变化可能受其他程序影响。
