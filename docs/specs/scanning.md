# 扫描规格（FR-02/03/04/09）

输入：版本化规则（user-temp-v1 / large-files-v1）、根目录、最小年龄/大小、排除目录快照、取消令牌。时间阈值 0～3650 天，默认 7；大文件默认 100 MB。临时规则根来自系统当前用户 Temp；大文件根必须由用户指定。固定本地卷、普通目录、非保护路径才接受。

输出：不可变候选（ID、规范路径、规则 ID/版本、卷和文件 ID、长度、UTC 时间、属性、硬链接数），错误样本、跳过/访问计数、取消与截断标志、开始结束时间。流式深度优先枚举，不读取文件内容，不创建/删除用户文件。所有候选默认不选。

性能：同步流式枚举器存活期间保持整条祖先目录句柄，同一目录的文件快照可复用该持有中的目录身份；递归退出恢复上一层，枚举结束释放上下文。执行阶段不使用扫描缓存，重新获取严格句柄与身份。

路径：只接受完整盘符绝对路径，GetFullPath 消解父目录，OrdinalIgnoreCase 目录边界比较；拒绝 ADS、设备/UNC、尾点/尾空格、通配符、Windows 保留名称。每级检查重解析点并核对句柄最终路径，禁止别名/短名绕过。异常分类包含权限、占用、消失、不可用、其他；目录失败影响该子树，不终止其他树。取消/上限返回已有候选，界面明确不完整。
